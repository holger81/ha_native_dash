# Full audit — 2026-10-14

Static audit of `259252b` (main == origin/main, clean tree). Four parallel passes:
networking core (HaClient/LiveCameraHub/MusicAssistant/CameraStreams), security
components (ManagementServer/TLS/Guard/credentials/kiosk), UI layer (all 24
compose files), and build/deps/manifests/tests. Headline findings re-verified by
hand against source; unverifiable agent claims are listed under *Rejected* so the
ledger stays trustworthy. The build itself could not be compiled in the audit
workspace (no Android SDK present).

Threat model reminder: single-site wall panels on a trusted LAN; the management
server can install APKs and force-lock the device, so it is the crown jewel.

## MEDIUM

### Networking / data
- `HaClient.kt:243-256` — `connect()` not under `messageLock`; reconnect loop + `connectFromUi` can interleave and orphan a live socket (identity check then silently drops its messages). Guard with same lock, `cancel()` previous socket inside.
- `HaClient.kt:185-186` — `baseUrl`/`token` plain vars written on UI thread, read from OkHttp/IO threads (`restGet`, `CameraStreams.resolve:94`) → stale-host/stale-token requests after reconnect. `@Volatile` or one immutable session-snapshot ref.
- `HaClient.kt:1000-1028` — `ensureMassIngress` has no single-flight and sits *inside* the 3-attempt `massCommand` retry loop; concurrent callers each fire 3 WS commands (last write wins), one call can burn minutes. `Mutex` + shared deferred, establish outside retry loop.
- `HaClient.kt:1815-1836,384-390` — `forecastViaSubscribe` has no timeout and a `success=true` result returns without resuming → caller + subscription entry hang until disconnect. `withTimeoutOrNull` + resume on success path.
- `HaClient.kt:1673,1009,1244` + `MusicAssistant.kt:176,266,318` — `?.jsonPrimitive` / bare `.jsonObject` throw `IllegalArgumentException` on unexpected network JSON (unlike guarded `handleMessage`). Use the `num()`-style safe accessors + `runCatching`.
- `HaClient.kt:161,167` + `CameraStreams.kt:48` — three independent OkHttpClients, never shut down in `release()` (dispatcher threads + pools leak on reconnect-with-new-client). Derive via `newBuilder()`; `evictAll()`/`shutdown()` on release. `CameraStreams.kt:163` reads a response without `use`.
- `LiveCameraHub.kt:212-216,384-398` — `Session.job/jpegJob/player/idleJob/listener` mutated from main + hub + caller threads; `startOne` check-then-act can spawn two decode loops; `pause()` can null a just-assigned job. Synchronize lifecycle or CAS an `AtomicReference`.
- `LiveCameraHub.kt:60-72,179-191` — idle-release armed only via `restorePlaceholder`/`resume`; sessions created through `start`/`ensureRunning`/`view()` that never gain a viewer leak ExoPlayer + MediaCodec forever; `sessions` map grows unbounded. Arm timer at creation, cap non-warm sessions.
- `CameraStreams.kt:161` — `coroutineContext.job.invokeOnCompletion { call.cancel() }` registers a fresh handler per JPEG poll (~3/s) on the long-lived `jpegJob`; handlers accumulate. Keep the `Disposable` and dispose in `finally`.
- `MusicAssistant.kt:243-246` — player matching falls back to substring containment: HA "Kitchen" can bind MASS "Kitchen Table" → volume/group commands drive the wrong speaker. Exact-normalized match or require unique containment.

### Security
- `NetworkGuard.kt:23,49-58,71-77` — 10-min **positive** DNS cache: first resolve private → cached → host later resolves public and the "last line of defence" interceptor never re-checks → classic DNS-rebind exfil of HA token. Validate the actually-connected address (custom `Dns`/socket factory), not the cached lookup.
- `res/xml/network_security_config.xml:9-13` — global cleartext + `src="user"` trust anchors for *all* hosts. **No certificate pinning exists anywhere in the codebase** (grep-verified), so any user CA installed on a panel MITMs the long-lived HA token. Scope cleartext/anchors to LAN `domain-config`s; system anchors elsewhere.
- `data/CredentialsStore.kt:414-418,421-478` — unsealed `credentials.json` honored until `recovery_sealed` pref exists; on fresh install that pref is never set → planted file injects HA URL/token/**management PIN** at first boot. Ignore unsealed inputs unless the user explicitly triggers import.
- `data/ManagementServer.kt:14,30,495` — NanoHTTPD binds the wildcard interface ("LAN-only" is convention only — VPN/tethering expose it); PIN compare is short-circuit `==` not constant-time; lockout is per-source-IP only, no global budget on a 4-8-digit PIN. Bind to `LanAddresses` NICs, `MessageDigest.isEqual`, global attempt counter.
- `data/ManagementServer.kt:133-151,404` — `/api/command` parses the full body (temp-file write) **before** auth → unauthenticated disk-DoS within the body limit; null remote IPs bucket under shared `"unknown"`. Auth/size-check first.
- `data/SecureRecovery.kt:83-95` — AES-GCM IVs are fine; the KDF secret is `ANDROID_ID` + fixed public salt — on devices upgraded from pre-API-26 ANDROID_ID is shared across all apps → any installed app can decrypt the public-Documents HA token/TLS key. Keystore-wrapped random key.
- `app/build.gradle.kts:149-150,138` — NanoHTTPD 2.3.1 unmaintained (CVE-2022-21230 inherent to its API — mitigate via bind restriction); BouncyCastle 1.78.1 behind several 2026 CVEs (upgrade ≥1.85); `security-crypto 1.1.0-alpha06` deprecated (replace with the existing SecureRecovery Keystore-backed pattern).
- `app/build.gradle.kts:88-96` — release builds: `isMinifyEnabled=false`, no `shrinkResources`, no `signingConfig`. Enable R8 + shrinking, feed signing from CI env.
- `ui/HaViewModel.kt:200-227` — `entityFlows`/`entityMapFlows` caches never evict; `stateIn(Lazily)` upstream jobs run forever → unbounded growth on a months-uptime panel. `SharingStarted.WhileSubscribed` + LRU cap.
- `ui/HomeMediaArea.kt:711-716` — volume slider calls `homeMediaSetVolume` per drag frame; VM path (`HaViewModel.kt:1088`) is undisdebounced (the `scheduleVolumeApply` 45 ms pattern exists elsewhere — reuse it).
- `ui/EntranceHome.kt:269,473` — widgets collect the **full** states map → recompose + rescan on every 80 ms flush. Use `entitiesFlow(…)`/`derivedStateOf`; full map only where lights-off chips need it.
- `ui/MoreInfo.kt:577-593` + `ui/widgets/CameraPlayer.kt:164-191` — snapshot loops decode full-size JPEGs on the composition path (5 s/30 s), bitmaps never recycled. Decode on IO with `inSampleSize` sized to the target box.

## Done well
- No committed secrets, keystores, or tokens (git-ls-files + content greps); `HA_TOKEN` env-only with hard fail.
- APK install path validates package, strictly-higher versionCode, and signing-fingerprint intersection before commit; device-admin receiver is a no-op behind `BIND_DEVICE_ADMIN`; kiosk endpoints use 256-bit random session tokens, HttpOnly/Secure/SameSite=Strict, PIN-binding invalidation, per-IP escalating lockout, HTML-escaped output.
- `allowBackup=false` + `hasFragileUserData`; NetworkGuard default-deny interceptor on shared clients; TTL'd + entry-capped caches; socket-identity checks under one lock; bounded MASS retries; 45 ms volume debounce + `volumeRequestRevision` guards; honest, current risk ledger in PLAN.md.

## Suggested order of attack
1. **H1** (one line) + PIN constant-time + global lockout budget — < 15 min.
2. **H4/H5** (two small edits) — kills the two 24/7-wear loops.
3. **H3** callback-out-of-lock refactor — small but test carefully.
4. **H2 + credentials.json planting** — decide migration end-date for unsealed fallback, then drop `?: it` paths.
5. NetworkGuard connect-time address validation; scope network_security_config; then dependency bumps (BC, security-crypto) and R8/signing.
